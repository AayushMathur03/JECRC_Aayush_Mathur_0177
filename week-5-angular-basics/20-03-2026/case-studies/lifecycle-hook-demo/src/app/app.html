🔄 Angular Lifecycle Hooks Demo

Understanding Component Lifecycle with Real-time Logging

📚 What This Demo Shows:

  • ngOnChanges: Triggered when input properties change (click "Update Status")
  • ngOnInit: Called once during component initialization
  • ngDoCheck: Runs on every change detection cycle
  • ngAfterContentInit/Checked: Content projection lifecycle
  • ngAfterViewInit/Checked: View initialization and checking
  • ngOnDestroy: Cleanup before component destruction (click "Toggle Child")

🎯 Interactive Demo:

Try these actions:

  • Update Status - Changes input data and triggers ngOnChanges
  • Toggle Child - Destroys/recreates component, triggering ngOnDestroy and ngOnInit
