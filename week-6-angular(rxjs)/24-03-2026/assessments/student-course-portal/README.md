# Question 9 — Student Course Portal

## Description

A training institute wants to build a Student Course Portal where:

- Students can view all available courses
- Click a course to see detailed information
- Navigate between pages easily

## Task

Design routing for the portal.

Include:

- Route paths
- What each route displays
- Navigation flow

## Routes

- `/dashboard` → Shows welcome page
- `/courses` → Displays course list
- `/course/:id` → Displays course details
- `/profile` → Displays student info

## Students Should Explain

- How data is fetched
- Why services are reusable
- How multiple components use the same data
